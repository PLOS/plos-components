The icon component renders an icon from an icon font. Icons are decorative by default and use Bootstrap Icons.

When to use this component

Use the icon component to add visual context to content, such as indicating success, error, or informational messages.

When not to use this component

Do not use icons alone to convey essential information. Always provide text labels or context for screen reader users.

Accessibility

Icons are rendered with aria-hidden="true" by default, making them decorative. For meaningful icons that convey information, provide alternative text in the parent context.

Parameters

Name Type Description Required Default
icon_name PresetIconName The name of the icon to fetch from the IconFontDictionary. Available options: check_circle, exclamation_circle, info_circle, add_item, delete_item, chevron_down. Yes (if custom_icon not provided) None
custom_icon string The name of the icon from an icon font (e.g., "bi bi-plus-lg"). Takes precedence over icon_name if both are provided. Yes (if icon_name not provided) None
size string Icon size. One of xs, sm, md, lg, xl. No md
display string Defines the CSS display mode. One of inline, block. No inline
field_id string An ID for the icon element. No None

Size Pixel Value

Display Options

Display Description
inline Allows the icon to sit alongside other HTML elements.
