It links each error to the affected input field via an anchor. When entries is empty the component renders nothing. {% endcomponent %}

{% component "plos_heading" level=2 %}Usage{% endcomponent %} {% component "plos_text_box" %} Build the entries list in your view: {% endcomponent %} entries = [ { "label": "Full name", "message": "Enter your full name", "anchor": "id_full_name", }, { "label": "Email address", "message": "Enter an email address in the correct format", "anchor": "id_email", }, ] {% component "plos_text_box" %} Then pass it to the component in your template: {% endcomponent %} {% verbatim %}{% component "plos_error_summary" entries=entries %}{% endcomponent %}{% endverbatim %} {% component "plos_text_box" %} Each entry requires three keys: {% endcomponent %}
  • label: human-readable label shown before the colon (e.g. "Patent 1")
  • message: the validation error text
  • anchor: the id of the target input, without the leading #
{% component "plos_text_box" %} An optional title parameter overrides the default heading "There is an issue". {% endcomponent %} {% endblock ds_content %}
