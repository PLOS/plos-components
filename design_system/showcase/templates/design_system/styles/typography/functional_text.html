Functional text

Fieldset legend

Legends reuse the heading type scale: --xl/--l/--m/--s map to heading-xl/l/m/s; the base legend maps to body-s. All are responsive, the type primitives carry both breakpoint values, so the classes reflow automatically. Implemented in plos-overrides.min.css. Sizes are in px.
