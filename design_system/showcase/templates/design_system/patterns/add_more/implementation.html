{% extends "design_system/base.html" %} {% block ds_title %} Add More Implementation - PLOS Design System {% endblock ds_title %} {% block ds_content %} {% component "plos_heading" level=1 %} Implementing the Add More Pattern {% endcomponent %} {% component "plos_text_box" %} The plos_add_more pattern is a complex component that manages a dynamic list of form items. It supports both standard form submissions and HTMX-powered partial updates for a smoother user experience. {% endcomponent %}
{% component "plos_heading" level=2 %} 1. Template Usage {% endcomponent %} {% component "plos_text_box" %} To use the pattern in your template, you need to call the plos_add_more component and provide an item slot. The item slot is used to render each individual item in the list. {% endcomponent %} {% verbatim %}{% component "plos_add_more" field_name="patents" item_label="patent" fields='[{"field_id": "patent_number", "required": True}]' max_items=10 htmx_url="/patterns/add-more/htmx/" %} {% fill "item" data="slot_data" %} {% component "plos_text_input" label="Patent reference or number" name="patent_number_{{ slot_data.index }}" field_id="patent_number_{{ slot_data.index }}" errors=slot_data.errors value="{{ slot_data.value|plos_dictionary_fetch:'patent_number' }}" %} {% endcomponent %} {% endfill %} {% endcomponent %}{% endverbatim %} {% component "plos_heading" level=3 %} Slot Data {% endcomponent %} {% component "plos_text_box" %} The item slot receives a slot_data object with the following properties:
  • index: The zero-based index of the current item (as a string).
  • is_first: A boolean indicating if this is the first item in the list.
  • errors: A dictionary of errors for the current item.
  • value: A dictionary of values for the current item.
{% endcomponent %}
{% component "plos_heading" level=2 %} 2. Handling HTMX Requests {% endcomponent %} {% component "plos_text_box" %} The component includes a built-in Django View to handle add and delete actions via HTMX. You should wire this view in your urls.py: {% endcomponent %} from plos_django_components.components.patterns.add_more.add_more import AddMore urlpatterns = [ # ... path("patterns/add-more/htmx/", AddMore.as_view(), name="add_more_htmx"), ] {% component "plos_text_box" %} The htmx_url parameter in the component call should match this URL. {% endcomponent %}
{% component "plos_heading" level=2 %} 3. Initial Values and State {% endcomponent %} {% component "plos_text_box" %} The component manages its state using the Django session. To provide initial values (e.g., from a database), you can pass a list of dictionaries to the values parameter. {% endcomponent %} initial_values = [ {"patent_number": "US1234567"}, {"patent_number": "EP9876543"}, ] {% verbatim %}{% component "plos_add_more" field_name="patents" values=initial_values %}{% endverbatim %} {% component "plos_text_box" %} When the component is first rendered, it will populate the session with these values. Subsequent interactions (add/delete) will update the session state. {% endcomponent %}
