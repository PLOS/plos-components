{% extends "design_system/base.html" %} {% block ds_title %} Add More - PLOS Design System {% endblock ds_title %} {% block ds_content %} {% component "plos_heading" level=1 %}Add More{% endcomponent %} {% component "plos_text_box" %} plos_add_more is built with HTMX to enable progressive enhancement. HTMX is not required. Without it, add and delete buttons submit the surrounding form normally and the page view re-renders the page. When HTMX.js is loaded, those same buttons POST the form to htmx_url (usually the page's own URL) and swap only the component's outer <div id="{name}-add-more"> in place, without a full page reload. The same view and template serve both cases. {% endcomponent %} {% component "plos_text_box" %} The page owns the error summary, so a form has one summary for all its fields. Build the add more entries with logic.error_summary_entries(errors, item_label), wrap the page's plos_error_summary in an element that is always rendered, and pass its id as error_summary_id. Add and delete then refresh that element too, so the summary never links to items that have moved or gone. {% endcomponent %} {% component "plos_text_box" %} The add and delete controls are part of this pattern, not variants of plos_button. Their styling (a tinted add button and a red delete link) only applies inside the add more pattern. {% endcomponent %}
