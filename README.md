# PLOS Components

This is a repository currently in an experimental mode. Components are divided into folders which are then deployed to individual packages.

## Packages

### django-components

The core package of reusable UI components built with the [django-components](https://github.com/django-components/django-components) framework. See [django-components/README.md](django-components/README.md) for installation and usage.

### design_system

A lightweight Django app for browsing PLOS design system styles and components interactively in a browser. See [design_system/README.md](design_system/README.md) for setup and structure.
